常用命令，
自己命名。

把经常输入的长命令保存成短名字，新开终端也能直接用。不用手改 .bashrc，临时命令还能设置有效期。

01

        
每天重复输入的那几条命令

        
SSH 登录、查看日志、运行项目脚本……命令不难，只是长，而且天天要敲。

      

      

        

          
以前手动维护

          
    
            
  • 长命令记不住，靠 Ctrl+R 翻历史记录
    • 
            
  • 写进 alias，要打开 .bashrc / .zshrc 改，再 source
    • 
            
  • 临时用一阵的别名，过后忘了删，配置越积越乱
    • 
            
  • 换台机器，又要从头配一遍
    • 
          

        

        

          
用 al一条命令搞定

          
    
            
  • 名字按自己的习惯取，想叫 fetch 还是 gf 都行
    • 
            
  • 保存后当前终端立即可用，新开终端也有效
    • 
            
  • 临时别名加 -t 7d，到期自动清理
    • 
            
  • al export / al import 迁移到其他机器
    • 
          

        

      

    

  


  
  

    

      

        
02

        
保存一次，直接使用

        
以 git fetch --all 为例，在 Git 仓库里获取所有远程的更新。

      

      

        

          STEP 1
          
保存命令

          
$ al set fetch as git fetch --all

          
以后 fetch 就代表这条命令。

        

        

          STEP 2
          
使用别名

          
$ fetch

          
等同于执行 git fetch --all，后面还可以追加参数。

        

        

          STEP 3
          
查看已保存的命令

          
$ al show

          
列出所有别名、最近使用时间和有效期。

        

      

      

        al set 别名 as 原始完整命令
        as 可以省略；同名别名会覆盖原配置。
      

    

  


  
  

    

      

        
03

        
常见用法

      

      

        

          
          
          
          
          
        


        

          

            

# 普通命令，后面可以追加参数
al set sh12 as ssh server12
sh12 -p 2222

# 包含管道、重定向或多步操作时，用单引号包住整条命令
al set logs as 'tail -f /data/reth.log | grep -i error'
logs

          

          
不加引号时，|、&&、> 会先被当前 shell 处理，只有前半段被保存。

        


        

          

            

# 7 天后过期；支持 30m、12h、7d、2w
al set -t 7d logs as 'tail -f /data/reth.log | grep -i error'

          

          
不指定 -t 则永不过期。过期的别名在重新加载或执行清理时失效；打开终端时最多每天自动清理一次。

        


        

          

            

al show                     # 查看全部：状态、最近使用、有效期、命令
al show ssh                 # 按名称或命令内容查找
al unset sh12               # 删除别名

al clean --unused 90d -n    # 预览：已过期或 90 天未使用的别名
al clean --unused 90d       # 确认后清理

          

          
al show 会把 30 天未使用的别名标记为 stale，只做提示，不会自动删除。

        


        

          

            

al export > aliases.tsv      # 导出
al import aliases.tsv        # 在另一台机器上导入，同名别名会被覆盖

# 或者直接通过 SSH 同步
al export | ssh server12 '~/.al/bin/al import -'

          

          
数据就是一个 TSV 文件：~/.al/aliases.tsv，也可以直接备份。

        


        

          

            

curl -fsSL https://ghfast.top/https://raw.githubusercontent.com/plantemeat/al/main/install.sh \
  | AL_RAW_BASE=https://ghfast.top/https://raw.githubusercontent.com/plantemeat/al/main bash

04

        
全部命令

      

      

        

          
命令说明

          
            
al set [-t TTL] [-f] NAME [as] CMD新增或覆盖别名。-t 设置有效期，-f 允许覆盖 PATH 中已有的命令

            
al unset NAME...删除一个或多个别名

            
al show [关键字]列出别名，可按名称或命令内容过滤

            
al clean [--unused DUR] [-n]清理过期或长期未使用的别名，-n 只预览

            
al export / import导出、导入别名，便于备份和迁移

            
al update从安装源更新工具

            
al help查看完整用法

          
        

      

    

  


  
  

    

      

        
05

        
注意事项

      

      

        

          
命名规则

          
只能包含字母、数字、_ 和 -，不能以数字或 - 开头。cd、ssh、sudo 等保留名称不能使用。

        

        

          
不会悄悄覆盖命令

          
与 PATH 中已有命令重名（比如 grep）时默认拒绝，确实需要时加 -f。

        

        

          
只导入可信文件

          
保存的命令通过 eval 执行，和你亲手输入一样。不要导入来路不明的别名文件。
